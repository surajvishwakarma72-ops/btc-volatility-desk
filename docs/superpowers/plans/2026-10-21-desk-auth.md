# Desk Login Auth + Re-enable Account Panels — Implementation Plan

> **For agentic workers:** Execute via superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Add a single-password → JWT login that guards `GET /api/v1/delta/signed`, and re-enable the account/P&L panels in the frontend (currently dormant), so only the logged-in operator sees live Delta account data.

**Architecture:** `@fastify/jwt` (already a dep) signs a JWT when the submitted password matches the server's `DESK_PASSWORD` (timing-safe). An `authenticate` preHandler guards `/signed`. The frontend's connect form becomes a password box; it stores the JWT and sends `Authorization: Bearer`. Delta key/secret stay server-side in `.env.prod`. Single-user: no DB writes for auth (JWT `sub` = the seeded desk user id).

**Tech Stack:** Fastify 5 (ESM), `@fastify/jwt@^9`, `node:crypto` (scrypt/timingSafeEqual), `@fastify/rate-limit`, Vitest. Frontend monolith `frontend/index.html`.

**Env (added on the VM `.env.prod` at deploy):** `DESK_PASSWORD`, `JWT_SECRET`, `DELTA_API_KEY`, `DELTA_API_SECRET`.

**Branch:** `feat/desk-auth` off `main` (`2553800`).

```typescript
import crypto from 'node:crypto';

const DESK_USER_ID = '00000000-0000-0000-0000-000000000001';
function passwordOk(submitted: string, expected: string): boolean {
  const a = Buffer.from(submitted);
  const b = Buffer.from(expected);
  if (a.length !== b.length) return false;
  return crypto.timingSafeEqual(a, b);
}
```
Inside the `authRoutes` plugin add (login is tightly rate-limited to blunt brute force):
```typescript
  fastify.post('/login', {
    config: { rateLimit: { max: 10, timeWindow: '1 minute' } },
  }, async (request, reply) => {
    const body = (request.body || {}) as { password?: string };
    const expected = process.env.DESK_PASSWORD;
    if (!expected) return reply.status(503).send({ success: false, error: 'Login not configured on server' });
    if (!body.password || !passwordOk(body.password, expected)) {
      return reply.status(401).send({ success: false, error: 'Wrong password' });
    }
    const token = await reply.jwtSign({ sub: DESK_USER_ID, role: 'trader' }, { expiresIn: '30d' });
    return reply.send({ success: true, token });
  });
```
> Note: per-route `config.rateLimit` requires `@fastify/rate-limit` registered globally (it is). `reply.jwtSign` is available once `@fastify/jwt` is registered (Task 1).

## Security notes
- Password compared timing-safe; never stored in the browser (only the JWT). Login endpoint rate-limited 10/min. JWT 30-day expiry; 401 forces re-login. Delta secret stays server-side. HTTPS only (Caddy). `JWT_SECRET` must be a strong random value (rotating it logs everyone out — fine for one user).

## Out of scope
Multi-user accounts, password reset UI, refresh tokens. (Single-user desk — YAGNI.)
