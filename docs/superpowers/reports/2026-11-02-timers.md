# Timer and DOM-churn changes (Task 6)

How it was found: `tools/perf/measure.mjs` (headless Chrome, browser totals per minute), plus one-off checks that count DOM
mutations per element and trace who makes them (MutationObserver + wrapped DOM methods).

| Where (approx. line) | What it did | Change |
|---|---|---|
| `v105_22Arrange` `arrange()` ~21252 vs `v133 moves()` ~47868 | Two owners of the Desk section order. arrange put the Tonight rail first; moves() put it after the vol row every 3 s. Each move fired arrange's MutationObserver, which re-appended all 8 Desk sections (charts included), on every page. | arrange now uses moves()'s order (rail after vol row). The visible result is the same, since moves() always won; the re-appending stops. |
| Drawing-pen `sweep()` ~34561, every 1 s | Rewrote `hidden` on 10 pen buttons every second (forcing a layout read each time), on every page. | Skip charts not on the open page; write `hidden` only when it changes. |
| Price-scale rail `sweep()` ~27568, every 1.5 s | Read layout, then wrote rail position and size for every chart, on every page. | Skip charts not on the open page; write a style only when it changes. |
| OrderFlow `render()` ~34031, every 1 s tick | Called `offsetParent` on three panels every second on every page (a forced layout). | First checks whether the panels sit on the open page (no layout read). |
| VoV loops ~26053 (1 s) and ~26065 (200 ms) | Repainted and re-aligned the IV-chart VoV panels on every page. | Run only while the Desk is open. |
| VoV align ~31835, every 400 ms | Forced a layout read per pane on every page. | Skip panes not on the open page. |
| Edge/Range legend ~41063 | `innerHTML` rewritten every second with the same text, on every page. | Write only when the text changes. |
| Impulse tag ~28174 | `className` re-set every second. | Write only when it changes. |
| `v127 apply()` ~46733 | Re-set `body[data-v127]` and `body[data-gpane]` every run. Body attributes restyle the whole page. | Write only when they differ. |

New shared helpers: `desk80.onOpenPage(el)` (is el on the open page, with no layout read) and `desk80.every(ms, fn, {page})`.

Left alone on purpose: alerts and alarm polls, the events/news collector (it feeds the shock alerts), the ATM-IV `render()`
(it feeds IV recording), the OrderFlow feed and pollers, the header clocks.

Result: see `2026-11-02-speed-and-paper.md`. The plan's stop rule (gain under 10%) was hit after this batch, so the
remaining ~150 intervals were not moved.
