Lock Gate State Variations Showcase
Demonstrating the exact error response banners, cooldown timer state, and credential validation feedback.
State 1: Failed Password Attempt
Invalid credentials. 4 attempts remaining before 10-minute terminal lockout.

Fires on HTTP 401 response from POST /auth/login. Clears the password input while preserving the entered username/email.

State 2: 10-Minute Lockout Cooldown
COOLDOWN ACTIVE: 5 failed attempts reached. Terminal unlocked in 09:42.

Triggers after 5 failed attempts in 10 minutes. Disables submit button until countdown reaches 00:00.

State 3: Zero-Trust Network Fence
✓ Delta WebSockets: PAUSED
✓ Delta REST /orders: BLOCKED
✓ Market Poller: PAUSED
✓ Auth Status: PENDING /auth/me

Proves acceptance criteria: zero financial or private API calls are dispatched until GET /auth/me succeeds.
